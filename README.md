##  Areas of Exploration

Throughout this assignment, I'll be exploring:

- **Computer Architecture:** Hardware, software and the Input-Process-Output-Storage cycle.
- **Command Line:** Navigating directories, manipulating files, command options and pipes.
- **Operating Systems:** Processes, storage, memory management and permissions.
- **Programming Concepts:** How compilers and interpreters execute programs.
- **Data Representation:** Binary, decimal, hexadecimal and character encoding.
- **Version Control:** Tracking changes, creating branches and working with Pull Requests.
- **Networking:** Network types, DNS, routers, protocols and client-server communication.

##  A Small Programming Project

One of the practical tasks involves developing a Python-based number converter.

The program will accept a decimal number and display its equivalent binary and hexadecimal representations.

To execute the program:

```bash
cd mission-05-numbers-data
python3 number_converter.py
```
