# Task 5.4 — How Is Text Stored?

### ASCII values

| Character | ASCII decimal code |
|---|---:|
| Uppercase A | 65 |
| Lowercase a | 97 |

### Why encoding is necessary

Computers cannot directly store letters and symbols as text in the same way humans read them. An encoding standard assigns numerical values to characters so that computers can store, process and exchange text consistently.

### Example of a character outside basic ASCII

The character € (Euro sign) is not included in basic ASCII.

UTF-8 can represent this character, along with many characters from different languages and writing systems.
