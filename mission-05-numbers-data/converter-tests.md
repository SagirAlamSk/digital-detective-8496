# Task 5.3 — Number Converter Tests

| Test number | Binary output | Hexadecimal output |
|---|---|---|
| 13 | 0b1101 | 0xd |
| 25 | 0b11001 | 0x19 |
| 42 | 0b101010 | 0x2a |

The program accepts a decimal whole number using input() and converts it into an integer using int(). The bin() function produces its binary representation, while hex() produces its hexadecimal representation.

I also included basic input validation so that negative numbers and invalid text are handled without crashing the program.
