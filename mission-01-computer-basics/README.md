# Mission 1 — Know Your Computer

## 1. Task / objective

The objective of this mission was to understand how a computer works by exploring the IPOS cycle (Input, Processing, Output and Storage). I also had to identify the hardware and software components used in everyday computing and look at examples of computer-based systems around us.

## 2. Work completed

### Task 1.1 — Tracing an activity using IPOS

For this activity, I chose **typing and saving a document on my computer**. It is something I commonly do, but breaking it down into individual stages helped me understand what happens behind the scenes.

| Stage | What happens? | Hardware / component involved |
|---|---|---|
| Input | I type text and use the keyboard to enter information into a document. | Keyboard |
| Processing | The computer processes the keystrokes and the application updates the document on the screen. | CPU and RAM |
| Output | The completed text is displayed on the monitor. | Display / Monitor |
| Storage | When I save the document, the information is written to storage so I can access it later. | SSD |

This activity helped me understand that a computer does not simply display whatever I type. Different components work together to receive, process, display and preserve information.

### Task 1.2 — Identifying hardware and software

I listed some common hardware components and software applications used in a computer system.

| Item / software name | Hardware or software? | Software type | Purpose |
|---|---|---|---|
| Keyboard | Hardware | Not applicable | Used to enter text and commands. |
| Mouse / Trackpad | Hardware | Not applicable | Used to control the pointer and interact with the computer. |
| Monitor | Hardware | Not applicable | Displays visual information. |
| SSD | Hardware | Not applicable | Stores files, applications and other data. |
| macOS | Software | Operating system | Manages hardware and provides an environment for applications. |
| Google Chrome | Software | Application software | Used to browse websites and access online services. |
| Visual Studio Code | Software | Application software | Used to write and edit code. |
| Disk Utility | Software | Utility software | Helps manage and inspect storage devices. |

The main difference I noticed is that hardware refers to the physical parts of a computer, whereas software consists of the programs and instructions that tell those parts what to do.

### Task 1.3 — Computer-based systems in everyday life

Computers are not limited to laptops and desktop systems. They are also built into many devices and services that we interact with regularly.

| System | Main purpose | One input | One output |
|---|---|---|---|
| ATM | Allows customers to withdraw cash and perform banking operations. | Card and PIN entry | Cash and transaction information |
| Smart TV | Displays television programmes and other digital content. | Remote-control input | Video and audio |
| Traffic signal system | Controls traffic movement at road intersections. | Vehicle sensors or pedestrian buttons | Traffic lights |

These examples show how computer systems are designed for different purposes. They receive information, process it according to programmed instructions and produce an appropriate response.

## 4. My understanding

Before completing this mission, I knew that computers had different components, but I had not really considered how they cooperate to complete an ordinary task.

The IPOS model made this easier to understand. Every time I type something, the keyboard provides input, the processor and memory help handle the information, the display provides output, and the storage device keeps the saved result.

I also understood that hardware and software depend on each other. Physical components alone cannot perform useful tasks without instructions, while software needs hardware to execute those instructions.

One interesting observation was that computer-based systems are everywhere. Even something like an ATM or a traffic signal follows the same basic idea of accepting input, processing information and producing output.

Overall, this mission helped me connect the theoretical concepts of computer fundamentals with devices and activities I encounter in everyday life.

## 6. How I resolved them

I reviewed the purpose of each software example and classified it according to what it does.

Applications such as browsers and code editors help users perform specific tasks, whereas utilities help maintain or manage the computer system.

This made the distinction easier to understand.
